# 📊 Power BI Dashboard: Sales, Cost & Profit Analysis

## 🔹 Project Overview
This project showcases an interactive **Power BI dashboard** built to analyze **sales, cost, and profit data across multiple countries**. It provides insights into customer behavior, profitability trends, and regional performance, helping businesses make data-driven decisions.

## 🔹 Features
- Visual analysis of **sales, cost, and profit** across different countries
- Customer segmentation by region and country
- Comparative analysis of profitability trends
- Interactive filters and slicers for dynamic exploration
- KPIs and charts for quick business insights

## 🔹 Dataset
- Sales dataset containing attributes such as:
  - Country
  - Customer details
  - Sales amount
  - Cost
  - Profit

## 🔹 Tools & Technologies
- **Power BI**
- **Excel / CSV dataset**
- **Data modeling and DAX calculations**

## 🔹 Expected Outcome
- A clear view of **business performance across countries**
- Identification of **high-value customers and profitable regions**
- Actionable insights for **strategic decision-making**
